Memory

Forgets by default. Remembers only if you say so.

Out of the box, Jerith forgets everything once a conversation ends. Persistence exists — as a strictly opt-in feature, never a silent one.

Opt-in

Database Memory Recall

A structured memory store you control. With recall enabled, Jerith can pull characters, project specs, brand guidelines, and past decisions on demand — so you stop re-explaining the same context every session.

  • With memory on, try asking
  • "Pull my protagonist's lore from last month's thread."
  • "What did we decide about the channel rebrand?"
  • "Recall the keyword map for this series."
Opt-in

Continuity Memory

Long-running work that picks up where it left off. Serialized stories, multi-week content calendars, and evolving worldbuilding stay coherent across sessions, threads, and channels.

  • With memory on, try asking
  • "Continue chapter 7 from where we left off."
  • "Check week 3 of my posting calendar."
  • "Keep my campaign timeline consistent."

Default behavior: forget. Nothing persists outside the active conversation. Both memory features stay off until a member explicitly turns them on — and can be switched off again at any time.

⛏ Jerith Coin (JER)

A coin minted by talking to Jerith

Jerith Coin is the community currency of the fleet: a real proof-of-work chain — JerithChain — where new coins are minted by conversations with Jerith, every balance is an on-chain signed transaction, and the whole node software is open source. Now in v1.1 — a single canonical validator, greatest-cumulative-work fork resolution, peer gossip between independent nodes, an offline chain-audit tool (verify-chain), and an exchange-ready machine RPC with Discord-free infrastructure wallets. Same economics, same address format, harder guarantees — details in the whitepaper §v1.1.

01The spec

  • Chain: JerithChain — SHA-256 proof-of-work at 18-bit difficulty, retargeting every 20 blocks toward ~60-second blocks
  • Supply: 1,000,000,000 JER hard cap · 200,000,000 premined at genesis to the founder · rewards halve every 210,000 blocks
  • Transfers: Ed25519-signed transactions, 0.1 JER fee burned on every send — balances are derived purely from the chain
  • Public record: live stats and the full ledger are on the chain explorer · full specification in the technical whitepaper

02Mining

  • Talk to mine: DMs or any server Jerith is in — every message has a chance to mint 2 JER for the sender
  • Explicit mining: ask Jerith to mine for the full block reward (~50 JER), throttled by cooldowns — 5 minutes after a success, 3 minutes after a miss
  • Opt-in by default: opt out and your would-be rewards flow to the community pool instead — your balance is never touched
  • Check anytime: just ask "how much JER do I have?" in any conversation

03Wallets & security

  • One wallet per Discord account — created automatically on first interaction; balance and history survive account moves via key export
  • Your keys: optional password + TOTP 2FA guard key export, wallet rebinding, and large sends; small sends auto-sign within a daily cap
  • Private keys in DMs only — never in servers; export is rate-limited and always confirmed with 2FA

04Run your own node

  • Open source: the whole chain is on GitHub — clone, pip install, run
  • AI-agent skill: give your own OpenClaw agent a JER wallet, sends, and mining — jerithchain on ClawHub · openclaw skills install jerithchain
  • Any machine: plain Python + SQLite; the fleet's own ledger is mirrored read-only to a Jetson over TLS-synced gRPC
  • Mirror or explore: run a follower to mirror JerithChain anywhere, or host your own explorer
  • Tested: 23 tests covering crypto, proof-of-work, wallets, and 2FA ship with the repo

FAQ

Questions, answered

How do I get access to Jerith AI?

Jerith runs inside private community Discord servers, and access is invite-based during alpha. Ask a current member to vouch for you, join the server, and a role unlock gives you access across channels and DMs.

Is there a public signup, app, or API?

Not right now. Alpha access is Discord-only for the private community. There is no public API, web app, or signup flow — if someone offers "public access" to Jerith, it isn't us.

Does Jerith remember previous conversations?

By default, no — outside the active conversation, Jerith forgets. Two memory features, Database Memory Recall and Continuity Memory, exist as opt-in options only: nothing is stored across sessions until a member explicitly enables them, and they can be switched off again at any time.

What does "early alpha" actually mean?

The assistant is live and used daily, but it's still forming. Depth varies by domain, behavior and features change frequently, and community feedback directly drives the roadmap. Expect noticeable improvements between visits.

What does it cost?

Nothing during alpha. Jerith is free for members of the private community throughout the alpha period.

What does "Mixture-of-Experts" mean?

MoE is an architecture with many specialized expert networks behind a router. Each request activates only the experts relevant to it, giving expert-level depth across many domains without proportional compute — part of how Jerith stays sharp and low-footprint.

What is Jerith Coin (JER) and how do I mine it?

JER is the community coin of Jerith AI — a real proof-of-work chain (JerithChain) capped at 1 billion coins. Every message you send Jerith has a chance to mine 2 JER, and you can explicitly mine for a 50-JER block reward (a few minutes' cooldown between attempts). Ask Jerith "how much JER do I have" any time — wallets are one-per-Discord-account, secured with optional password + 2FA, and fully on-chain. The node software is open source on GitHub if you want to run your own node.

What hardware does Jerith actually run on?

Seven machines: a gaming desktop (RTX 4060), three Mac Minis, an NVIDIA Jetson Orin Nano Super, and five MacBooks — pooled into one compute fabric by nmonit and one storage mount by drive-nmonit. The fabric runs the model pool and mines Jerith Coin; a read-only chain ledger mirror lives on the Jetson.

Is Jerith fully local?

Local-first, not local-only. The full 16-model routing pool runs on the two-GPU home fabric (Ollama behind LiteLLM). A purpose-built model router picks the lane per request — chat, coding, vision, medical, embeddings — and reads live VRAM from nmonit before dispatching. When local models are exhausted or rate-limited, the chain transparently reaches datacenter-backed models via OpenRouter and Groq.
